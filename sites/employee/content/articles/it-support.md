# IT サポート窓口

社内システム・端末・ネットワークに関する一次対応ガイドです。

## 対応範囲

- パスワードリセット（SSO / 社内アカウント）
- 社用 PC・モニターの故障申告
- Microsoft 365 / 社内チャットの利用方法
- VPN・Wi-Fi 接続トラブル

## 一次対応（自分で試す）

1. **再起動** — PC・ルーターを再起動
2. **ブラウザのキャッシュ削除** — Web アプリの不具合時
3. **ステータスページ確認** — 外部 SaaS 障害の有無

## エスカレーション

上記で解決しない場合は、PLuG から IT 部へ連絡してください。次の情報があると早いです。

- 社員 ID
- 利用端末（Windows / Mac）
- エラーメッセージのスクリーンショット
- 発生時刻と再現手順

## 緊急連絡

全社システム障害（メール・基幹システム停止）の場合は、緊急連絡網に従い IT 部長へ直接連絡します。通常の問い合わせは PLuG を利用してください。
